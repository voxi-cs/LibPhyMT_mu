Introduction

It is true that Real Analysis is a pure mathematical subject; nevertheless, it lies at the heart of modern physics. One can say that the purpose of real analysis is to make precise the ideas of limits, continuity, differentiation, integration, and infinite processes on the real line, and to prove exactly when and why they work. But one must not undermine the significance of this study. Real analysis did not come into being as the work of one person or one group of individuals. Rather, it slowly emerged over many centuries through the contributions of many mathematicians. The earliest clear precursor can be traced back to the ancient Greeks: ideas such as the method of exhaustion, developed by Eudoxus and used powerfully by Archimedes, already contained the spirit of rigorous limiting arguments. Much later, in the 17th century, Newton and Leibniz created calculus, but the subject still lacked a fully precise foundation. In the 19th century, Bernard Bolzano began to push analysis toward modern rigor, and Augustin-Louis Cauchy, in his 1821 Cours d'analyse, gave limits, continuity, and convergence a much firmer logical basis. Then Karl Weierstrass brought the epsilon-delta style of rigor that became the standard language of analysis. After that, Richard Dedekind and Georg Cantor helped clarify the real numbers and completeness, and in the early 20th century Henri Lebesgue expanded integration through measure theory. In this way, real analysis was not born all at once; it was built slowly, through centuries of careful work, until it became the subject we know today. Later, these ideas also helped shape other branches of mathematics, such as functional analysis, which became central in quantum mechanics and quantum field theory (QFT).

Nevertheless, in this chapter on real analysis, our goal is to walk together with the reader through the vast and fascinating field of real analysis, hoping to look deeply into the subject.

Revisiting The Sets

It is assumed that the reader has a basic understanding of what a set is. Here, we would like to formalize our understanding of sets so that we do not have problems with the upcoming notations and terms that we will be using throughout the chapter.

Definition: A set is a well-defined collection of distinct objects, called elements or members, regarded as a single mathematical object.

If \(x\) is an element of a set \(\textit{A}\), then we write \(x \in \textit{A}\); otherwise, we write \(x \notin \textit{A}\).

Here, \(\in\) reads as in or belongs to, and \(\notin\) as not in or does not belong to.

To create a set, we write a notational structure as below:

\[ \textit{A} = \{ x : \text{a certain condition on } x \} \]

Throughout this chapter, we will use \(\mathbb N = \{1,2,3,\dots\}\) and \(\mathbb N_0 = \{0,1,2,3,\dots\}\).

The elements of a set can be anything. They could be vectors, and they can form a vector space, or a set can contain alphabets. There is no restriction on what a set can contain, but we can indeed restrict certain sets to contain only certain things.

We can create a set of all even numbers and call it \(\textit{E}\), as: \[ \textit{E} = \{x : x = 2n,\ \text{for some } n \in \mathbb{Z}\} \] We can similarly create a set of odd numbers, \(\textit{O}\), as: \[ \textit{O} = \{x : x = 2n + 1,\ \text{for some } n \in \mathbb{Z}\} \] Notice that we could also do the same using the \(mod\) notation and the set of all integers \(\mathbb{Z}\). Then the set of even numbers can be written as: \[ \textit{E} = \{x \in \mathbb{Z} : x \equiv 0 \pmod{2}\} \] Similarly, for odd numbers: \[ \textit{O} = \{x \in \mathbb{Z} : x \equiv 1 \pmod{2}\} \]

Definition: Let \(A\) and \(B\) be two sets. The union of \(A\) and \(B\), denoted by \(A \cup B\), is the set of all elements that belong to \(A\), or to \(B\), or to both.

\[ A \cup B = \{x : x \in A \text{ or } x \in B\} \]

Let sets \(\textit{A} = \{1,2,3,5,7,11\}\) and \(\textit{B} = \{1,2,4,7,5\}\), then their union is: \[ \textit{A} \cup \textit{B} = \{1,2,3,5,7,11\} \cup \{1,2,4,7,5\} = \{1,2,3,4,5,7,11\} \] If we give another example, the union of the set of odd numbers and the set of even numbers is the set of all integers \(\mathbb{Z}\): \[ \textit{E} \cup \textit{O} = \{\dots,-6,-4,-2,0,2,4,6,\dots\} \cup \{\dots,-5,-3,-1,1,3,5,\dots\} = \{x \in \mathbb{Z} : x \text{ is even or odd}\} = \mathbb{Z} \]

Definition: Let \(A\) and \(B\) be two sets. The intersection of \(A\) and \(B\), denoted by \(A \cap B\), is the set of all elements that belong to both \(A\) and \(B\).

\[ A \cap B = \{x : x \in A \text{ and } x \in B\} \]

The intersection of the set \(\textit{A} = \{1,2,3,5,7,11\}\) and \(\textit{B} = \{1,2,4,7,5\}\) is just the set of all elements that are both in \(\textit{A}\) and \(\textit{B}\): \[ \textit{A} \cap \textit{B} = \{1,2,3,5,7,11\} \cap \{1,2,4,7,5\} = \{1,2,5,7\} \] The intersection of \(\textit{E}\) and \(\textit{O}\) is the empty set \(\varnothing\); it is because the even set contains all even numbers and the odd set contains all odd numbers, so there is nothing common between them. Hence: \[ \mathit{E}\cap\mathit{O} = \varnothing \]

Definition: Let \(A\) and \(B\) be two sets. We say that \(A\) is a subset of \(B\), written \(A \subseteq B\), if every element of \(A\) is also an element of \(B\).

\[ A \subseteq B \iff \forall x,\ (x \in A \Rightarrow x \in B) \]

If \(A \subseteq B\) and \(A \neq B\), then \(A\) is called a proper subset of \(B\), written \(A \subset B\).

In case you are unfamiliar with it, here \(\forall\) reads as “for all,” meaning that for all \(x\) that are in \(\textit{A}\), they must also be in \(\textit{B}\).

The set of all even numbers \(\textit{E}\) is said to be a subset of all integers \(\mathbb{Z}\), and we write it as \(\textit{E} \subseteq \mathbb{Z}\). More specifically, \(\textit{E}\) is a proper subset of \(\mathbb{Z}\), and hence \(\textit{E} \subset \mathbb{Z}\). The same is true for the set \(\textit{O}\). If it is otherwise and \(\textit{A}\) is not a subset of \(\textit{B}\), then we write it as \(\textit{A} \nsubseteq \textit{B}\).

Definition: Let \(A\) be a subset of a universal set \(U\). The complement of \(A\), denoted by \(A^c\) or \(U - A\), is the set of all elements of \(U\) that do not belong to \(A\).

\[ A^c = U - A = \{x \in U : x \notin A\} \]

Here, \(A^c\) reads as A complement, and \(U - A\) reads as U minus A or the set difference of \(U\) and \(A\).

Let \(\mathbb{Z}\) be the universal set, then \(\textit{E}^c = \mathbb{Z} - \textit{E} = \textit{O}\).

Now that we are familiar with the notations, let us show some examples and introduce a few more crucial notations that are going to be useful.

Theorem-4.001: De Morgan's Laws

Let \(\textit{A}\) and \(\textit{B}\) be subsets of a universal set \(\textit{U}\). Then \[ (\textit{A} \cup \textit{B})^c = \textit{A}^c \cap \textit{B}^c \] and \[ (\textit{A} \cap \textit{B})^c = \textit{A}^c \cup \textit{B}^c. \]

Proof:

We first show that \[ (\textit{A} \cap \textit{B})^c \subseteq \textit{A}^c \cup \textit{B}^c. \] Let \(x \in (\textit{A} \cap \textit{B})^c\). Then \(x \notin \textit{A} \cap \textit{B}\), so \(x \notin \textit{A}\) or \(x \notin \textit{B}\). Hence \(x \in \textit{A}^c \cup \textit{B}^c\). Therefore, \[ (\textit{A} \cap \textit{B})^c \subseteq \textit{A}^c \cup \textit{B}^c. \] Conversely, suppose \(x \in \textit{A}^c \cup \textit{B}^c\). Then \(x \notin \textit{A}\) or \(x \notin \textit{B}\), so \(x \notin \textit{A} \cap \textit{B}\). Thus \(x \in (\textit{A} \cap \textit{B})^c\). Therefore, \[ \textit{A}^c \cup \textit{B}^c \subseteq (\textit{A} \cap \textit{B})^c. \] Hence, \[ (\textit{A} \cap \textit{B})^c = \textit{A}^c \cup \textit{B}^c. \] Similarly, we show that \[ (\textit{A} \cup \textit{B})^c = \textit{A}^c \cap \textit{B}^c. \] Let \(x \in (\textit{A} \cup \textit{B})^c\). Then \(x \notin \textit{A} \cup \textit{B}\), so \(x \notin \textit{A}\) and \(x \notin \textit{B}\). Hence \(x \in \textit{A}^c \cap \textit{B}^c\). Therefore, \[ (\textit{A} \cup \textit{B})^c \subseteq \textit{A}^c \cap \textit{B}^c. \] Conversely, suppose \(x \in \textit{A}^c \cap \textit{B}^c\). Then \(x \notin \textit{A}\) and \(x \notin \textit{B}\), so \(x \notin \textit{A} \cup \textit{B}\). Thus \(x \in (\textit{A} \cup \textit{B})^c\). Therefore, \[ \textit{A}^c \cap \textit{B}^c \subseteq (\textit{A} \cup \textit{B})^c. \] Hence, \[ (\textit{A} \cup \textit{B})^c = \textit{A}^c \cap \textit{B}^c. \]

Let us see an example to brush up some basic ideas.

EXAMPLE

Let us consider the sets: \[ A_n = \{n,n+1,n+2,\dots\} \quad \forall n \in \mathbb N \] These sets are: \[ A_1 = \{1,2,3,4,\dots\} \] \[ A_2 = \{2,3,4,5,\dots\} \] \[ A_3 = \{3,4,5,6,\dots\} \] And so on.

Here notice that \(A_1\) contains all the elements of \(A_2,A_3,\dots\), so we can say: \[ A_1 \supseteq A_2 \supseteq A_3 \supseteq \dots \] Here now let us take the union of all such sets, that is: \[ \bigcup_{n=1}^{\infty} A_n = A_1. \] Notice that since all the sets \(A_2,A_3,\dots\) are subsets of \(A_1\), if we combine them by union, then we will just get \(A_1\). Therefore, we can say the countable union of \(A_n\) is \[ \bigcup_{n=1}^{\infty} A_n = A_1. \]

Now let us think about the intersection of all those sets. The countable intersection of all those sets is: \[ \bigcap_{n=1}^{\infty} A_n = \varnothing. \] The countable intersection is empty because, suppose there is some \(m\) that is in all such sets. Then \(m\in A_m\), but notice that \(m\notin A_{m+1}\), and therefore we have a contradiction. So there is no such \(m\).

The Real Number set \(\mathbb R\)

To work with the real number set \(\mathbb R\), we first need to define what it is. The early work of real analysis was an attempt to build a rigorous definition of the real number set. Much of the work of real analysis was constructed for this purpose. After building enough mathematical understanding of the real numbers, we were able to construct a rigorous construction of \(\mathbb R\) from the rational number set \(\mathbb Q\). But first we need that mathematical understanding to truly understand that construction, and later in this chapter we shall see that construction of \(\mathbb R\). But for now we will work with the following definition of the real number set \(\mathbb R\).

Definition: The Real Number System The real numbers are a set \(\mathbb{R}\) containing \(\mathbb{Q}\) as a subfield, equipped with addition, multiplication, and an order such that \(\mathbb{R}\) is an ordered field and satisfies the Axiom of Completeness.

Field Properties:

Addition and multiplication on \(\mathbb{Q}\) extend to all of \(\mathbb{R}\). Addition and multiplication are commutative and associative, and multiplication distributes over addition: \[ a+b=b+a,\qquad ab=ba, \] \[ (a+b)+c=a+(b+c),\qquad (ab)c=a(bc), \] \[ a(b+c)=ab+ac \] for all \(a,b,c\in\mathbb{R}\).

Additive Inverse:

For every \(a\in\mathbb{R}\), there exists \(-a\in\mathbb{R}\) such that \[ a+(-a)=0. \]

Multiplicative Inverse:

For every nonzero \(a\in\mathbb{R}\), there exists \(a^{-1}\in\mathbb{R}\) such that \[ aa^{-1}=1. \]

Order:

The familiar ordering on \(\mathbb{Q}\) extends to \(\mathbb{R}\) and is compatible with the field operations. In particular, \[ a \lt b \text{ and } c\gt 0 \quad\Longrightarrow\quad ac \lt bc \] for all \(a,b,c\in\mathbb{R}\).

Axiom of Completeness(AoC):

Every nonempty subset of \(\mathbb{R}\) that is bounded above has a least upper bound in \(\mathbb{R}\).

In the definition, most of the concepts are quite reasonable and understandable, but the Axiom of Completeness needs a little bit of our time to truly appreciate it.

Supremum and Infimum

Definition: Boundedness Suppose we have a set \(A \subset \mathbb R\), the set \(A\) is said to be bounded above if there exists a \(b \in \mathbb R\) such that for all \(a \in A \), \(a \le b\). Here \(b\) is called a upper bound.

And the set is said to be bounded below if there exists a \(l \in \mathbb R\) such that for all \(a \in A\), \(a \ge l\). Here \(l\) is called a lower bound.

In the above animation you can see what we mean by upper bound and lower bound. When a set is bounded above, it just means we can find at least one real number such that it is greater than or equal to all the elements in the set \(A\), and similarly, being bounded below means we can find a real number that is less than or equal to all the elements in the set \(A\). It is like being able to draw some boundary around \(A\) on either side when drawn on the number line.

Now let us define the most important part of analysis.

Definition: Supremum Suppose we have a set \(A \subset \mathbb R\), a real number \(s \in \mathbb R\) is said to be the supremum or least upper bound of \(A\) if:

  1. \(s\) is a upper bound of \(A\).
  2. For any upper bound \(b\) of \(A\), \(s \le b\).

Supremum of a set \(A\subset \mathbb R\) is denoted as: \[ s = \sup A. \] Or sometimes as: \[ s = \text{lub } A. \]

It is easy to see that the supremum of a set is unique, and it is easy to prove that.

Definition: Infimum Suppose we have a set \(A \subset \mathbb R\), a real number \(i \in \mathbb R\) is said to be the Infimum or greatest lower bound of \(A\) if:

  1. \(i\) is a lower bound of \(A\).
  2. For any lower bound \(l\) of \(A\), \(i \ge l\).

Infimum of a set \(A\subset \mathbb R\) is denoted as: \[ i = \inf A. \] Or sometimes as: \[ i = \text{glb } A. \]

Let us show you an example that should clear up any confusion you might have.

EXAMPLE

Give the set below: \[ A = \left\{ 2 - \frac{2}{n+1}: n \in \mathbb N_0 \right\} \] Find its supremum and infimum.


Notice that the set \(A\) is: \[ A = \left\{0 , 1, \frac{4}{3}, \frac{3}{2},\dots \right\}. \] And we defined the set such that its elements are: \[ 2 - \frac{2}{n+1} \quad \text{for } n \in\mathbb N_0. \] Notice what happens as \(n \to \infty\): \[ \lim_{n \to \infty} 2 - \frac{2}{n+1} = 2. \] So, \(2\) is approached by the elements of \(A\), but \(2\) itself is not an element of \(A\): \[ 2\notin A. \]

Now go back to the definitions. We can see that the set \(A\) is bounded above by all real numbers \(b \ge 2\), and bounded below by all real numbers \(l\le 0\). Now notice the definition of the supremum says \(\sup A\) has to be an upper bound and it has to be the smallest upper bound, which in this case we can see is \(2\). It is because \(2\) is an upper bound, while the elements of \(A\) can be made arbitrarily close to \(2\) from below. Therefore, no number smaller than \(2\) can be an upper bound. Thus: \[ \sup A = 2. \] Similarly, \(0\) is in \(A\), and every element of \(A\) is greater than or equal to \(0\). Therefore: \[ \inf A = 0. \] An important thing to notice here is that \(2\notin A\), which means the supremum and infimum of a set do not necessarily have to be in the set, as in this example. An example of a set where the infimum and supremum both belong to the set is: \[ B = \{1,2,3,4\}. \] Here \(\max B = \sup B = 4 \in B\) and \(\min B = \inf B = 1 \in B\). And in the case of \(A\), even though \(\min\) is defined on \(A\) and \(\min A = \inf A = 0\), \(\max\) is not defined on \(A\).

Now we can talk about the Axiom of Completeness. It says, "Every nonempty subset of \(\mathbb R\) that is bounded above has a least upper bound in \(\mathbb R\)." What this is saying is that every nonempty subset of \(\mathbb R\) that does not go off without bound in the positive direction has a supremum. That is, the set \(A=[0,\infty)\) is not bounded above and thus has no supremum, but the set \(A=\{2\}\cup(4,5)\cup[6,9)\cup(9,12]\cup[15,18]\) is bounded above and thus has a supremum, namely \(\sup A=18\). The Axiom of Completeness is an axiom, and thus we accept it as true instead of proving it.

The least-upper-bound property holds for the real number set \(\mathbb R\), but it does not hold for \(\mathbb Q\) or for \(\mathbb I\), with the inherited order. Below is an example showing the failure for \(\mathbb I\); it is for you to give an example for \(\mathbb Q\). Take it as a H.W.

EXAMPLE

Show that the least-upper-bound property does not hold on \(\mathbb I\), using the set \[ A = \{a_n:n\in\mathbb N_0\}, \qquad a_0=\sqrt{2},\qquad a_{n+1}=\sqrt{2+a_n}. \]


First, every \(a_n\) is irrational. We know \(a_0=\sqrt{2}\) is irrational. If some \(a_n\) with \(n\ge1\) were rational, then \[ a_{n-1}=a_n^2-2 \] would also be rational, and repeating this argument would eventually make \(a_0\) rational, which is a contradiction. Therefore \(a_n\in\mathbb I\) for every \(n\), so \(A\subseteq\mathbb I\).

Here are the values of the first few elements: \[ \begin{aligned} a_0 &= \sqrt{2} \approx 1.41421356237, & a_1 &= \sqrt{2+\sqrt{2}} \approx 1.84775906502,\\ a_2 &= \sqrt{2+\sqrt{2+\sqrt{2}}}\approx 1.96157056081, & a_3 &= \sqrt{2+\sqrt{2+\sqrt{2+\sqrt{2}}}}\approx 1.99036945334. \end{aligned} \]

Notice that \(a_n \lt 2\) for every \(n\). This can be shown by induction: \(a_0=\sqrt{2} \lt 2\), and if \(a_n \lt 2\), then \[ a_{n+1}=\sqrt{2+a_n} \lt \sqrt{4}=2. \] Let \[ e_n=2-a_n. \] Then \(e_n>0\), and \[ e_{n+1} =2-\sqrt{4-e_n} =\frac{e_n}{2+\sqrt{4-e_n}} \lt \frac{e_n}{2}. \] Therefore, \[ 0 \lt e_n \lt \frac{e_0}{2^n}, \] and hence \(e_n\to0\). Thus \(a_n\to2\).

Since every element of \(A\) is less than \(2\), \(2\) is an upper bound of \(A\). Since \(a_n\to2\), the elements of \(A\) can be made arbitrarily close to \(2\) from below. Therefore: \[ \sup_{\mathbb R} A=2. \] But \(2\notin\mathbb I\). Moreover, if \(s\in\mathbb I\) were an upper bound of \(A\), then \(s>2\). The number \[ t=\frac{s+2}{2} \] is also irrational and satisfies \(2 \lt t \lt s\). Since every \(a_n \lt 2 \lt t\), \(t\) is a smaller irrational upper bound. Therefore, \(A\) has no least upper bound in \(\mathbb I\). Hence the least-upper-bound property does not hold on \(\mathbb I\).

The same idea works for \(\mathbb Q\): its least-upper-bound property also fails. It is for you to find an example. Take it as a H.W.

Lemma-4.001: Characterization of the Supremum

Suppose \(A \subseteq \mathbb R\), and let \(s\) be an upper bound of \(A\). Then \(s\) is the supremum of \(A\), \(s = \sup A\), if and only if, for every \(\epsilon \gt 0\) there exists an \(a \in A\) such that \[ s - \epsilon \lt a. \]

Proof:

For the forward direction, suppose \(s = \sup A\), and let \(\epsilon \gt 0\) be arbitrarily chosen. Since \(s - \epsilon \lt s\), \(s - \epsilon\) cannot be an upper bound of \(A\), because \(s\) is the least upper bound of \(A\). Therefore, there must be some \(a \in A\) for which \[ s - \epsilon \lt a. \] This proves the lemma in one direction.

Conversely, suppose \(s\) is an upper bound of \(A\) with the property that for every \(\epsilon \gt 0\), there exists an \(a \in A\) such that \[ s - \epsilon \lt a. \] Notice that this means that if \(b\) is any number less than \(s\), then \(b\) cannot be an upper bound of \(A\). To see this, let \[ \epsilon = s-b. \] Since \(b \lt s\), we have \(\epsilon \gt 0\). Therefore, there exists an \(a \in A\) such that \[ s-\epsilon \lt a. \] But \(s-\epsilon = b\), so: \[ b \lt a. \] Hence, \(b\) is not an upper bound of \(A\).

Now, since \(s\) is already an upper bound of \(A\), and every number less than \(s\) is not an upper bound, \(s\) must be the least upper bound of \(A\). Therefore: \[ s = \sup A. \]

Lemma-4.002: Characterization of the Infimum

Suppose \(A \subseteq \mathbb R\), and let \(s\) be a lower bound of \(A\). Then \(s\) is the infimum of \(A\), \(s = \inf A\), if and only if, for every \(\epsilon \gt 0\) there exists an \(a \in A\) such that \[ a \lt s + \epsilon. \]

Proof:

For the forward direction, suppose \(s = \inf A\), and let \(\epsilon \gt 0\) be arbitrarily chosen. Since \(s \lt s + \epsilon\), \(s + \epsilon\) cannot be a lower bound of \(A\), because \(s\) is the greatest lower bound of \(A\). Therefore, there must be some \(a \in A\) for which \[ a \lt s + \epsilon. \] This proves the lemma in one direction.

Conversely, suppose \(s\) is a lower bound of \(A\) with the property that for every \(\epsilon \gt 0\), there exists an \(a \in A\) such that \[ a \lt s + \epsilon. \] Notice that this means that if \(b\) is any number greater than \(s\), then \(b\) cannot be a lower bound of \(A\). To see this, let \[ \epsilon = b-s. \] Since \(b \gt s\), we have \(\epsilon \gt 0\). Therefore, there exists an \(a \in A\) such that \[ a \lt s+\epsilon. \] But \(s+\epsilon = b\), so: \[ a \lt b. \] Hence, \(b\) is not a lower bound of \(A\).

Now, since \(s\) is already a lower bound of \(A\), and every number greater than \(s\) is not a lower bound, \(s\) must be the greatest lower bound of \(A\). Therefore: \[ s = \inf A. \]

These lemmas are going to be important in analysis. Now let us explore some mathematical properties we get from the real number set \(\mathbb R\) as a consequence of accepting the Axiom of Completeness.

Properties of \(\mathbb R\)

Below this theorem proves an important consequence of completeness. It shows that the real number line has no "gaps" in the sense that bounded sets cannot have a missing least upper bound. This is different from density: \(\mathbb Q\) and \(\mathbb I\) are both dense in \(\mathbb R\), even though neither is complete. The real number set \(\mathbb R\) is an extension of the set of rational numbers, and one way to think about its construction is as filling the missing limits of \(\mathbb Q\). Later, when we discuss topology, you will see that \(\mathbb R\) is the closure of both \(\mathbb Q\) and \(\mathbb I\).

Theorem-4.002: Nested Interval Property(NIP)

Suppose we have a collection of closed intervals \[ I_n=[a_n,b_n], \] such that \(I_{n+1} \subseteq I_n\). Then what we get is: \[ I_1 \supseteq I_2 \supseteq I_3 \supseteq I_4 \supseteq \dots \] Then the countable—we haven't talked about what countable means, but soon you will know—intersection of all these sets is: \[ \bigcap_{n=1}^{\infty} I_{n} \neq \varnothing. \]

Proof:

In order to prove this theorem we need to use a logical consequence of AoC, so let us consider the following set: \[ A = \{a_n: n \in \mathbb N\}. \]

In the animation you can see what the set \(A\) represents. For any fixed \(n\), \(b_n\) is an upper bound for the set \(A\). Indeed, if \(m \lt n\), then \(I_n\subseteq I_m\), so \(a_m\le a_n\le b_n\). If \(m\ge n\), then \(I_m\subseteq I_n\), so \(a_m\le b_n\). Therefore, \(A\) is bounded above. Since \(A\) is nonempty and bounded above, we know by AoC that there exists a supremum of \(A\). Let it be \(x\): \[ x = \sup A. \] Since \(x\) is an upper bound of \(A\), we have \[ a_n\le x \] for every \(n\). And since each \(b_n\) is an upper bound of \(A\), and \(x\) is the least upper bound, we have \[ x\le b_n \] for every \(n\). Therefore, for every interval \(I_n=[a_n,b_n]\), \[ a_n \le x \le b_n. \] That means \(x\) is in all intervals \(I_n\). And therefore: \[ x \in \bigcap_{n=1}^{\infty} I_{n} \implies \bigcap_{n=1}^{\infty} I_{n} \neq \varnothing. \]

Let us now look at a direct consequence of \(AoC\), which will be useful to prove a very important fact about \(\mathbb R\).

Theorem-4.003: Archimedean Property

  1. Given any real number \(x \in \mathbb R\), there exists an \(n \in \mathbb N\) such that \(n \gt x\).
  2. Given any real number \(y \gt 0\), there exists an \(n \in \mathbb N\) such that \(\frac{1}{n} \lt y\).

Proof:

To prove this theorem we need to use AoC, as it is a direct consequence of AoC, so let us first prove the first part. Suppose, for the sake of contradiction, that there is some \(x \in \mathbb R\) such that: \[ n \le x \] for every \(n \in \mathbb N\). This means that \(\mathbb N\) is bounded above. Since \(\mathbb N\) is bounded above, we know by AoC that there exists a supremum of \(\mathbb N\). Let it be \(s\): \[ s=\sup\mathbb N. \]

Now \(s-1\) cannot be an upper bound of \(\mathbb N\), because \(s\) is the least upper bound. Therefore, there must exist some \(n \in \mathbb N\) such that: \[ n>s-1. \] Adding \(1\) to both sides we get: \[ n+1>s. \] But \(n+1 \in \mathbb N\), which means we have found a natural number larger than \(s\). This contradicts the fact that \(s\) is an upper bound of \(\mathbb N\). Therefore, \(\mathbb N\) cannot be bounded above. Hence, given any \(x \in \mathbb R\), there exists an \(n \in \mathbb N\) satisfying: \[ n\gt x. \]

Now for the second part, let \(y\gt 0\). Since \(\frac{1}{y}\in \mathbb R\), by the first part there exists an \(n \in \mathbb N\) such that: \[ n>\frac{1}{y}. \] Since \(n\gt 0\) and \(y\gt 0\), taking reciprocals reverses the inequality: \[ \frac{1}{n}\lt y. \]

The theorem below is quite important for analysis. It shows that the rational numbers are spread throughout the real number line. That is, choose any real number \(a \lt b\); it doesn't matter how close \(a\) and \(b\) become, you can always find a rational number \(r\) that is in between \(a\) and \(b\) on the real number line. And the same is true of the irrational numbers, as we will prove.

Theorem-4.004: Density of \(\mathbb Q\) in \(\mathbb R\)

Given any two real numbers \(a \lt b\), there always exists a rational number \(r\) such that: \[ a \lt r \lt b. \]

Proof:

We know a rational number has the form: \[ \frac{m}{n}\in\mathbb Q \] where \(m\in\mathbb Z\) and \(n\in\mathbb N\). Since \(n\in\mathbb N\), we have \(n>0\). For \(\mathbb Q\) to be dense in \(\mathbb R\) we want the following condition to hold: \[ a \lt \frac{m}{n} \lt b \implies na \lt m \lt nb. \]

We can choose \(n\) such that: \[ \frac{1}{n} \lt b-a. \]

Now, by the standard integer-part property, we can choose an integer \(m\) such that \[ m-1\le na \lt m. \] (This property follows from the Archimedean Property together with the well-ordering of \(\mathbb N\).)

From the right side of the inequality we get: \[ na \lt m. \] This implies: \[ a \lt \frac{m}{n}. \]

Now for the upper bound, from the left side of the inequality we have: \[ m-1\le na. \] So, \[ m\le na+1. \]

Since \(\frac{1}{n} \lt b-a\), multiplying by \(n\) gives \[ 1 \lt n(b-a), \] so \[ na+1 \lt na+n(b-a)=nb. \] Therefore, \[ m \lt nb. \] This implies: \[ \frac{m}{n} \lt b. \]

So we have our upper and lower bounds: \[ a \lt \frac{m}{n} \lt b. \] Therefore, \(\mathbb Q\) is dense in \(\mathbb R\). That is what we mean when we say a set is dense in \(\mathbb R\).

We have said that the irrational number set is also dense in \(\mathbb R\), and now we will prove that as well. But my recommendation to you: try to prove it by yourself.

Theorem-4.005: Density of the Irrational Numbers in \(\mathbb R\)

Let the set of irrational numbers be \(\mathbb I=\mathbb R \setminus \mathbb Q\), then \(\mathbb I\) is dense in \(\mathbb R\).

Proof:

Let \(a,b\in\mathbb R\) with \(a \lt b\). Since \(\mathbb Q\) is dense in \(\mathbb R\), there exists a rational number \(q\in\mathbb Q\) such that \[ a-\sqrt{2} \lt q \lt b-\sqrt{2}. \]

Let \[ x=q+\sqrt{2}. \]

Then \[ a \lt x \lt b. \]

Also, \(x\) is irrational. If \(x\) were rational, then \[ \sqrt{2}=x-q \] would be rational, which is a contradiction. Therefore \(x\in\mathbb I\).

Since \(a\) and \(b\) were arbitrary real numbers with \(a\lt b\), we have shown that for every interval \((a,b)\), there exists an \(x\in\mathbb I\) such that \(a\lt x\lt b\). Therefore, \(\mathbb I\) is dense in \(\mathbb R\).
